# Problem Statement

## Project Title
Movie Ticket Booking System (Console Based, Python)

## Problem
Booking movie tickets on paper or by asking at a counter is slow. Staff have to
keep checking which seats are free, it is easy to book the same seat twice, and
calculating the bill or cancelling a ticket takes time.

## Aim
To build a simple menu-driven Python program that lets a user see the movies,
check which seats are free, book one or more seats, get the total bill, view a
booking, and cancel it.

## Objectives
1. Show a list of movies with show time, ticket price and free seats.
2. Show a seat layout that clearly marks free and booked seats.
3. Let the user book one or many seats and stop them from booking a seat that is already taken.
4. Calculate the total amount (number of tickets x ticket price) and show a booking summary.
5. Let the user view booking details using the booking ID.
6. Let the user cancel a booking (after confirmation) and make those seats free again.
7. Keep running until the user chooses Exit.

## Scope
- Runs in the console (command prompt / terminal).
- Uses sample movie data stored inside the program (no database).
- Data is kept only while the program is running.

## Input
- Menu choice, movie number, seat numbers (like A1,A2), booking ID, and y/n confirmations.

## Output
- Movie list, seat layout, booking summary, booking details, and status messages.

## Tools Used
- Python 3
- Any text editor or IDE (IDLE, VS Code, PyCharm)
